# DevOps_CI_CD Terraform Project

## Структура проєкту

- `main.tf` — головний файл, підключає всі модулі.
- `backend.tf` — конфігурація бекенду для зберігання стану Terraform у S3 та блокування через DynamoDB.
- `variables.tf` — глобальні змінні.
- `outputs.tf` — глобальні вихідні значення.
- `modules/` — директорія з модулями:
  - `s3-backend/` — модуль для S3-бакету та DynamoDB для зберігання та блокування стану.
  - `vpc/` — модуль для створення VPC, підмереж, шлюзів, маршрутів.
  - `ecr/` — модуль для створення репозиторію ECR.

## Команди для ініціалізації та запуску

```sh
terraform init      # Ініціалізація Terraform та бекенду
terraform plan      # Перевірка плану змін
terraform apply     # Застосування змін
terraform destroy   # Видалення всіх ресурсів
```

## Пояснення модулів

### s3-backend
- Створює S3-бакет для зберігання стану Terraform.
- Створює DynamoDB-таблицю для блокування стану (state locking).
- Забезпечує безпечне та централізоване зберігання стану.

### vpc
- Створює VPC з публічними та приватними підмережами.
- Додає інтернет-шлюз, NAT-шлюз, маршрути та асоціації маршрутних таблиць.
- Використовується для ізоляції та організації мережевої інфраструктури.

### ecr
- Створює репозиторій Amazon ECR для зберігання Docker-образів.
- Налаштовує політику доступу та сканування образів.
- Використовується для CI/CD пайплайнів та деплойменту контейнерів.
